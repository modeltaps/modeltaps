# よくある質問

## クォータと課金

**クォータとは何ですか。金額にはどう換算されますか。**

クォータはサイト内部の記帳単位で、500,000 クォータ = $1 です。画面上では通常そのまま米ドル金額で表示されます。

**1 回のリクエストでいくら引かれたか、どう照合できますか。**

従量課金のモデルの場合、費用 = 入力 token × 入力単価 + 出力 token × 出力単価 で、入力と出力はそれぞれ独立して計算されます。回数課金のモデルは呼び出しが成功した時点で固定の 1 回あたり価格が課金されます。「ログ」ページで任意のレコードを展開すると、今回の実際の入力価格、出力価格、グループ倍率、最終的な費用を確認できます。完全なルールは [料金と価格](/ja/guide/billing) を参照してください。

**アカウントのクォータは足りているのに、クォータ不足と表示されるのはなぜですか。**

その API キー自身のクォータを確認してください。API キーのクォータとアカウントのクォータは別々に計算され、API キーのクォータはそのキー 1 本の最大使用量のみを制限します。どちらか一方でも不足するとリクエストは拒否されます。

**同じモデルなのに、他の人と価格が違うのはなぜですか。**

価格 = モデル単価 × グループ倍率であり、グループごとに倍率が異なります。「利用可能なモデル」ページの右上でグループを切り替えると、そのグループでの価格を確認できます。

## 呼び出しエラー

**利用可能なチャネルがないと表示されます。**

現在のグループに、そのモデルを提供できるチャネルがないということです。「利用可能なモデル」ページでそのモデルが自分のグループで利用できるか確認するか（「利用可能なもののみ表示」を有効にすると絞り込めます）、API キー設定でそのモデルがあるグループに切り替えてください。

**「当前分组负载已饱和，请稍后再试」（現在のグループの負荷が飽和しています。しばらくしてから再試行してください）と表示されます。**

上流がレート制限または一時的な利用不可を返しています。しばらくしてから再試行してください。継続して発生する場合はサイト管理者にお問い合わせください。

**サードパーティクライアントで `Failed to fetch` が発生します。**

- 接続先アドレスと API Key が正しく入力されているか確認してください。
- HTTPS が有効かどうか確認してください。ブラウザーは HTTPS ページから送信される HTTP リクエストをブロックします。
- 一部のクライアントではアドレスをルートドメインに入力する必要があり、余分なパスを付けてはいけません。

**あるモデルに「価格未設定」と表示されますが、使えますか。**

保証できません。サイトがそのモデルに価格を設定していない場合、呼び出しが直接拒否される可能性があります。価格ページで価格が付いているモデルをご利用ください。

## 組織

**組織メンバー予算の上限を超えたと表示されます。**

管理者があなたに周期予算（毎日 / 毎週 / 毎月）を設定しています。当該周期の使用量が上限に達すると、あなたの組織 API キーは拒否され、次の周期でリセットされるか、管理者が予算を引き上げるまで続きます。現在の使用量は組織の「メンバー」ページで確認できます。

**組織から外された後、自分の API キーはまだ使えますか。**

使えません。組織を退出した場合や外された場合、その組織配下のあなたの API キーは無効化されます。個人 API キーと個人クォータは影響を受けません。

**個人クォータを組織に移せますか。**

移せます。組織の「概要」ページで「クレジットを振替」をクリックすると、個人クレジットを組織のクレジットプールへ一方向に移せます。**振替後は取り消せません**ので、金額を確認してから送信してください。

**組織の消費はどこで確認できますか。**

組織の「利用状況」ページで、メンバー別・API キー別・モデル別・日付別に消費明細を確認できます。一般メンバーが全員分の利用状況を閲覧できるかどうかは、組織設定によって決まります。
