# API キーとクォータ

API キーは Modeltaps を呼び出すときに使用する認証情報です。アプリケーションごと、環境ごとに API キーを分けて作成すると、ログや利用状況で「誰が使っているか」を明確に区別でき、問題が起きたときも他のアプリケーションに影響を与えずにそのキーだけを停止できます。

## API キー一覧

「API キー」ページでは所有するすべての API キーが一覧表示されます。既定で表示される列は次のとおりです。

| 列 | 意味 |
| --- | --- |
| API キー | 名称とキー（キーは既定でマスクされ、展開して表示 / コピーできます） |
| グループ | その API キーが使用するチャネルグループ。未指定の場合は「ユーザーに従う」と表示されます |
| 有効期限 | 「無期限」、残り時間、または「期限切れ」 |
| 最終使用 | 前回呼び出しに成功した時刻。一度も呼び出していない場合は「未使用」と表示されます |
| 利用量 | 累計の使用クォータと、あわせて「本日」の使用量 |
| 上限 | 残りクォータまたは「上限なし」。周期を設定している場合は当該周期の上限と次回リセット時刻を表示します |
| 状態 | スイッチ。その API キーを直接有効化 / 停止できます |

右上の「列設定」で列の表示 / 非表示を切り替えられます（例：既定で非表示の「作成日時」）。上部のフィルターバーでは API キー名称で検索できます。

各行の操作メニューからは、キーのコピー、チャットクライアントで開く、「テストコマンド」、「OpenClaw に接続」、その API キーの「利用状況」と「ログ」へのジャンプ、編集、削除を実行できます。

## API キーの新規作成と編集

「API キーを新規作成」をクリックすると編集パネルが開きます。いくつかのブロックに分かれています。

### 基本情報

- **名称**（必須）：ログと利用状況分析はいずれも API キー名称で集計されます。名称を変更しても過去の記録は変わらないため、最初に決めておくことをおすすめします。
- **無期限 / 有効期限**：既定では無期限です。スイッチをオフにすると具体的な期限を指定でき、期限を過ぎるとその API キーは使用できなくなります。

### クォータと周期

クォータの入力欄は 1 つだけで、その意味は「リセット周期」によって変わります。

- **クォータ未入力・周期未選択**：上限なし。API キー自体には上限を設けませんが、実際の消費は引き続きアカウントの利用可能クォータに制約されます。
- **クォータ入力・周期未選択**：総額の制限。累計消費がそのクォータに達すると API キーは停止されます。
- **クォータ入力・周期を選択**（毎日 / 毎週 / 毎月）：クォータは「周期ごとのクォータ上限」になります。周期の境界の 0 時に自動でリセットされ、アカウント残高から追加で差し引かれることはありません。周期を選択する場合、クォータは 0 より大きい必要があります。

パネルには、リセットに使用されるサイトのタイムゾーンと週の開始曜日（月曜または日曜）が表示されます。一覧の「上限」列には次回リセット時刻が表示されます。

::: warning クォータは 2 層構造です
API キーのクォータは API キー自身の最大使用量のみを制限し、実際に差し引かれるのはアカウントのクォータです。アカウントのクォータが不足していると、API キーが上限なしでもリクエストは失敗します。逆に API キーのクォータを使い切ると、アカウントに残高があっても遮断されます。
:::

### チャネルグループ

- **グループ**：その API キーのリクエストがどのチャネルグループを通るかを指定します。空欄の場合はアカウントのグループに従います。
- **予備グループ**：メイングループが利用できない場合、リクエストは予備グループを経由します。

グループが削除済み、または使用権限がない場合、一覧のグループラベルが目立つ色で警告表示されます。

### 詳細設定

- **モデル制限**：有効にすると、その API キーで使用を許可するモデルを選択できます。1 つも選択しない場合はすべてのモデルを許可する意味になります。特定のアプリケーションを数個のモデルに限定したい場合に便利です。
- **IP ホワイトリスト**：有効にすると 1 行に 1 つの IP または CIDR（例：`192.168.1.1`、`10.0.0.0/8`）を入力でき、これらのアドレスからのリクエストのみが許可されます。
- **ハートビート設定（実験的）**：リクエストが長時間データを返さない場合、クライアントがタイムアウトで切断されることがあります。有効にすると、設定した待機秒数を超えても応答がないときに、Modeltaps が 5 秒ごとにハートビートを送信して接続を維持します（非ストリームでは空行、ストリームでは `::PING` を返します）。待機時間は 30〜90 秒の範囲で設定できます。リクエストが中継プログラムを経由する場合、有効化は推奨されません。

## API キーのテスト

操作メニューから「テストコマンド」を選択すると、OpenAI / Claude / Gemini の 3 つのタブでそのまま実行できる `curl` が表示されます。コマンドには実際のキー、サイトアドレス、選択したモデルがすでに入力されているため、ターミナルにコピーして実行すれば API キーが使えることを確認できます。モデルはドロップダウンで検索して切り替えられます。

いずれかのプロトコルで「このプロトコルで利用できるモデルがありません」と表示される場合は、現在のグループに対応する種類のチャネルが存在せず、そのプロトコルは当面利用できません。OpenAI タブでテストしてください。

## 停止と削除

- 一覧の状態スイッチで API キーをいつでも停止 / 復帰できます。停止した API キーでの呼び出しは直接拒否されます。
- 「削除」は元に戻せません。削除する前に、そのキーを使用している本番アプリケーションがないことを確認してください。

## クォータの補充

アカウントのクォータは「チャージ」ページ（サイドバー下部の残高行から開けます）で補充でき、オンライン決済と交換コードの 2 つの方法に対応しています。チャージ記録はユーザーメニューの「請求」ページ、「アカウント明細」タブで確認してください。詳しくは [クイックスタート](/ja/guide/quickstart) の説明を参照してください。

組織に切り替えると、このページで管理するのは組織 API キーになります。クォータは組織のクレジットプールから引かれ、メンバーごとに周期予算を設定することもできます。詳しくは [組織](/ja/guide/organization) を参照してください。
