# 利用状況とログ

Modeltaps は 3 つの階層の利用状況ビューを提供します。「ダッシュボード」で現在の概況を、「利用状況」で推移と要因を、「ログ」でリクエスト 1 件ずつを追跡できます。

## ダッシュボード

ログイン後の既定ページで、本日のリクエスト数、本日の消費額、本日の Token 量、利用可能なクォータに加え、直近 7 日間の推移、直近 7 日間のモデル利用状況、キャッシュヒット率、割引による節約額などの概況を表示し、現在利用可能なモデルを一覧します。

## 利用状況

「利用状況」ページでは、消費金額、Token 量、リクエスト数の変化を時間軸で表示します。

### 期間

上部の期間セレクターでは、相対期間（直近 15 分 / 30 分 / 1 時間 / 3 時間 / 1 日 / 2 日 / 1 週間 / 1 か月 / 1 年）、暦上の期間（今日、昨日、今週、先週、今月、先月、今年、昨年）、およびカスタム範囲を選択できます。既定では直近 1 週間を表示します。

### 指標カード

4 枚のカードにそれぞれ消費金額、リクエスト数、Token 量、キャッシュヒット率が表示されます。各カードにはミニ推移線と、前の期間と比較した増減率が付きます。

### グラフ

- **費用（$/日）**：日次の消費金額
- **リクエスト数（回/日）**：日次のリクエスト回数
- **Token の内訳**：日次の入力 / 出力 Token
- **プロンプトキャッシュ**：キャッシュ済みと未キャッシュの Token の比較

### 要因分析とフィルター

ページには Top モデル、Top API Keys、Top アプリケーションの 3 枚のランキングカードがあり、費用がどこに集中しているかをすばやく特定できます。フィルターバーではモデル、API キー、アプリケーションを複数選択で絞り込むことができ、グラフとランキングも連動します。

### エクスポート

「CSV をエクスポート」をクリックすると、現在の期間とフィルター条件のデータを CSV として書き出せます。日付、リクエスト数、消費金額、入力 Tokens、出力 Tokens が含まれます。ファイルには UTF-8 BOM が付いており、そのまま Excel で開けます。現在の範囲にデータがない場合は、エクスポートできる内容がない旨が表示されます。

## ログ

「ログ」ページには、リクエストと消費が 1 件ずつ記録されます。

ページ上部には「リクエストログ」「Midjourney」「非同期タスク」の 3 つのタブがあり、それぞれ `?tab=log`、`?tab=midjourney`、`?tab=task` に対応するのでブックマークや共有もできます。既定は「リクエストログ」です。組織コンテキストでは「リクエストログ」のみで、他の 2 つのタブは表示されません。以下の説明はすべて「リクエストログ」タブについてです。

### ヒストグラム

一覧の上にある「リクエスト量」ヒストグラムは、リクエスト数、費用、Tokens を時間で集計して表示します。展開 / 折りたたみが可能です。

### 列

既定の列には時刻、グループ、API キー、アプリケーション、種類、モデル、モダリティ、状態（終了理由）、所要時間、スループット、入力、出力、費用などが含まれます。右上の「列設定」で列の表示 / 非表示を自由に切り替えられます。

このうち：

- **モダリティ** は、その呼び出しがどの種類の API に該当するかを示します。対話、補完、Responses、ベクトル化、リランキング、コンテンツモデレーション、画像生成 / 編集 / バリエーション、音声合成 / 文字起こし / 翻訳、リアルタイム、動画などがあります。
- **状態（終了理由）** は、その生成がなぜ終了したかを示します。完了、長さによる打ち切り、コンテンツフィルター、ツール呼び出し、エラーがあります。
- **所要時間** の中の `t/s` は、出力 Token 数を総生成時間で割った値で、生成速度を表します。

### フィルター

フィルターバーは複数の軸に対応しており、列挙型の項目は選択と除外のどちらも指定できます。

- API キー名称、モデル、アプリケーション（プリセット項目から選択できるほか、任意の値を直接入力することもできます）
- 終了理由、モダリティ
- 最低消費額（クォータ）、最低 Token 数
- リクエスト ID（本サイトのトラッキング ID、完全一致）

期間セレクターは「利用状況」ページと同じです。「更新 / 検索条件をクリア」ボタンでワンクリックでリセットできます。

### 1 件ごとの明細

任意の行をクリックすると、そのリクエストの明細を展開できます。概要、リクエストに関する情報（アプリケーション、API キー、リクエスト ID、上流のリクエスト ID、終了理由、ストリーミングかどうか）、および消費明細が含まれます。消費明細では、各種 Token（入力 / 出力のテキスト、音声、画像、推論、キャッシュの読み書きなど）の課金内訳と対応する倍率が展開され、グループ倍率、実際の入力 / 出力価格、元の課金額と実際の課金額が表示されます。課金方式は「Token 単位」と「回数単位」を区別します。

サイトとアカウントで完全なリクエスト / レスポンスの保存が有効になっている場合は、明細でその呼び出しのリクエストボディとレスポンスボディも確認できます。無効な場合、保存期間を過ぎている場合、閲覧権限がない場合は、それぞれの説明が表示されます。保存のスイッチは有効化した後の新しいリクエストにのみ適用され、過去のリクエストが遡って記録されることはありません。

### ID で検索する

「その他の操作」から「ID で検索」を選び、ログ ID を貼り付けると、該当する 1 件を正確に特定して明細を直接開けます。

### エクスポート

「その他の操作」の「CSV をエクスポート」では、現在のフィルター条件に従ってログを書き出します。

## 会計記録

チャージや招待などの会計記録はリクエストログには含まれません。いずれもサイドバー下部のユーザーメニューから開く「請求」ページのタブです。

- **アカウント明細**タブ：残高の変動と取引明細を確認できます。
- **月次請求書**タブ：月単位で集計された請求書を確認・ダウンロードできます。
