# 組織

組織を使うと、同僚と 1 つのクレジットプールを共用し、API キーや利用状況のビューを共有しながら、メンバーごとに予算と利用可能なモデルを設定できます。このページでは画面上で実行できる組織関連の操作をすべて紹介します。

::: tip 組織機能が使えるかどうか
組織機能はサイト単位で有効化されます。サイドバー上部の ID カードから「コンテキストの切り替え」メニューを開けない場合、現在のサイトではこの機能が有効になっていません。
:::

## 個人コンテキストと組織コンテキスト

サイドバー上部の ID カードがコンテキスト切り替えの入口です。開くと「個人」と所属する各組織を切り替えられます。

- **個人コンテキスト**：自分のクォータと個人 API キーを使用します。カードの下半分には個人残高、利用状況の進捗、リクエスト数が表示されます。
- **組織コンテキスト**：組織のクレジットプールを使用します。カードには組織名、自分のロールバッジ、メンバー数、および組織プールの残高が表示されます（残高はオーナーと管理者のみ表示され、メンバーには「残高は管理者のみ表示できます」と表示されます）。さらに「今期の予算」の行があり、自分の当該周期の使用量 / 上限と進捗バーが表示されます（自分に予算が設定されていない場合は「無制限」と表示）。組織に組織の周期予算が設定されている場合、オーナーと管理者には「組織予算」の行も表示されます。

切り替えは全体に適用されます。ある組織に切り替えると、「API キー」「利用状況」「チャージ」などのページで表示・作成する内容はすべてその組織に属します。選択内容は記憶され、ページを再読み込みしても同じコンテキストのままです。

切り替えメニューで現在の組織の下にある「組織を管理」を選ぶと組織管理ページに移動します。サイドバーの「組織」から直接開くこともできます。

## ロールと権限

組織には 3 つのロールがあります。

| 機能 | メンバー | 管理者 | オーナー |
| --- | --- | --- | --- |
| 組織のクレジットプールでモデルを呼び出す | ✅ | ✅ | ✅ |
| 自分の組織 API キーを作成・管理する | ✅ | ✅ | ✅ |
| 組織 API キーを閲覧する（すべて） | — | ✅ | ✅ |
| 組織の利用状況を閲覧する | 自分の分（設定による） | 全員分 | 全員分 |
| メンバーを招待する、メンバーのアカウントを代理作成する | — | ✅ | ✅ |
| メンバーのロール変更、メンバーの削除 | — | ✅ | ✅ |
| メンバー予算とモデルホワイトリストの設定 | — | ✅ | ✅ |
| 組織情報と設定の変更 | — | ✅ | ✅ |
| 組織へのチャージ、個人クレジットの振替 | — | ✅ | ✅ |
| 監査ログの閲覧 | — | ✅ | ✅ |
| オーナー権限の移譲、組織の解散 | — | — | ✅ |

管理者どうしは互いに操作できず、自分自身に対してロール変更や削除を実行することもできません。権限のない入口は画面上で非表示になり、サーバー側でも改めて検証されます。

## 組織の作成と参加

### 組織を作成する

コンテキスト切り替えメニューの下部で「組織を作成」をクリックし、組織名を入力して送信します。作成に成功すると自動的に新しい組織へ切り替わり、あなたがそのオーナーになります。1 アカウントで作成できる組織数はサイトによって制限されます。

### 招待から参加する

個人コンテキストで「組織」ページを開くと「マイ招待」が表示されます。

- **個別招待**：管理者がユーザー名またはメールアドレスであなたを指定した場合、招待が一覧に直接表示され、招待者と有効期限が示されます。「承認」で参加、「拒否」で無効化されます。
- **招待リンク**：受け取った招待リンクまたは招待コードを「招待リンクで組織に参加」の入力欄に貼り付け、「参加」をクリックします。

## 概要

組織管理ページの「概要」タブには組織のアバター、名称、自分のロールが表示され、その下に次のカードがあります。

- **クレジットプール残高**：組織が現在利用できるクレジット。オーナーと管理者のみ表示されます。
- **メンバー数**
- **今期の組織予算**：当該周期の使用済みクォータ / 上限が表示され、その下に周期と次回リセット日時が示されます。組織予算が未設定の場合は「無制限」と表示されます。オーナーと管理者のみ表示されます。
- **作成日時**

オーナーと管理者は、残高カードの「クレジットを振替」から自分の個人クレジットを組織プールに移すこともできます。

::: warning 振替は取り消せません
個人クレジットの組織プールへの振替は一方向の操作で、移した後に個人アカウントへ戻すことはできません。振替前に現在の個人残高が表示され、入力できる数量はそれを超えられません。この機能はサイト側で無効化されている場合があります。
:::

## メンバー管理

メンバー管理はユーザーメニューの「設定」ページ、組織グループの「メンバー」にあります。メンバー一覧にはユーザー、ロール、参加日時が表示され、管理者にはさらに「予算」列と操作列が表示されます。検索ボックスではユーザー名、表示名、メールアドレスで現在のページを絞り込めます。

管理者向けの表示では、上部に「メンバー / 招待」の 2 つのセグメントがあり、後者には処理待ちの招待が一覧表示されます。

### メンバーを招待する

「メンバーを招待」をクリックし、いずれかの方法を選びます。

- **個別招待**：メールアドレスまたはユーザー名（いずれか一方）を入力します。相手は自分の「マイ招待」で承認し、1 回のみ使用できます。
- **リンク招待**：招待リンクを生成します。作成すると自動的にクリップボードへコピーされます。「最大使用回数」を設定でき（0 を入力すると無制限）、ログイン済みのユーザーであれば誰でもリンクから参加できます。

どちらの方法でも、参加後のロール（メンバーまたは管理者）を指定でき、無期限にするか有効期限を指定するかを選べます。

「招待」セグメントでは、処理待ちの招待の被招待者、ロール、状態、使用回数、有効期限を確認できます。リンク招待はリンクを再度コピーでき、処理待ちの招待はいずれも「取り消し」が可能です。

### 他の人のアカウントを直接作成する

相手がまだサイトのアカウントを持っていない場合、管理者は「メンバーを新規作成」をクリックし、ユーザー名とパスワード（必須）、および表示名、メールアドレス、ロールを入力できます。作成するとそのアカウントはそのまま本組織のメンバーになります。選択できるロールは自分のロールを超えられません。作成後は予算を設定したり、そのメンバー用に組織 API キーを作成したりできます。

### ロールの変更と削除

メンバー行の操作からロールを変更できます。メンバーの削除には確認が必要で、**削除されたメンバーの組織 API キーは無効化されます**。

### メンバー予算とモデルホワイトリスト

メンバー行の予算値（または操作内の「予算とホワイトリスト」）をクリックすると設定パネルが開きます。

- **周期予算**：「予算制限なし」を選ぶか、毎日 / 毎週 / 毎月でクォータ上限を設定します。設定するとパネルに当該メンバーの当該周期の使用済みクォータが表示され、一覧では「使用量 / 上限 · 周期」の形式で示されます。上限を超えると赤色で表示されます。
- **モデルホワイトリスト**：そのメンバーが呼び出せるモデルを選択します。**空欄の場合は組織の既定設定に従い、追加の制限は行われません。**

### 組織の周期予算

メンバーごとの上限に加えて、管理者は組織全体に対する合計上限を設定できます。「設定」ページ組織グループの「予算」で「予算制限なし」を選ぶか、毎日 / 毎週 / 毎月でクォータ上限を入力し、「保存」をクリックすると反映されます。

- 組織予算が集計するのは**当該周期における全メンバーの合計消費**です。使い切ると、次の周期に入るまで組織内のすべてのリクエストが拒否されます。
- 2 つの上限は同時に効きます。1 回のリクエストはまず自分のメンバー予算、次に組織予算で判定され、どちらにも余裕がある場合のみ実際にモデルへ送られます。いずれかを使い切った時点で即座に拒否され、費用は発生しません。
- 予算の周期を変更すると当該周期の使用済みクォータは 0 から数え直しになります。「予算制限なし」に戻すと、各メンバーの予算のみが有効になります。
- 使用状況は「概要」タブの「今期の組織予算」カードとサイドバーの ID カードで確認できます。いずれもオーナーと管理者のみ表示されます。

## 組織 API キーとチャージ

組織コンテキストに切り替えると、「API キー」ページで管理するのは組織 API キーになります。メンバーは自分が作成した API キーのみ表示・管理でき、オーナーと管理者は組織内のすべての API キーを表示できます。API キーの作成方法は個人 API キーと同じです。詳しくは [API キーとクォータ](/ja/guide/tokens) を参照してください。

組織 API キーは組織のクレジットプールを消費し、あなたのメンバー予算とモデルホワイトリストの制約を受けます。

::: warning API キーはメンバー資格とともに失効します
メンバーが削除された場合や自分から組織を退出した場合、その組織 API キーは無効化されます。組織が解散された場合も、組織内の API キーは同様に失効します。
:::

組織コンテキストで、サイドバー下部の残高行から「チャージ」ページを開くと、ページ上部に今回のチャージが組織のクレジットプールに入る旨が表示されます。

- オーナーと管理者はオンラインチャージと交換コードによるチャージを実行でき、入金はすべて組織プールに入ります。
- 一般のメンバーのサイドバー残高行には「チャージ」への導線が表示されません。チャージページの URL（`/panel/topup`）に直接アクセスした場合も、「組織へのチャージはオーナーと管理者のみ操作できます」という案内のみが表示されます。

交換コードには用途が限定されている場合があります。「制限なし」のコードは個人でも組織でも交換でき、「組織のみ」のコードは組織コンテキストで組織クレジットプールにのみ入金でき、「個人のみ」のコードは個人アカウントにのみ入金できます。誤ったコンテキストで交換すると「この交換コードは組織アカウント専用です」または「この交換コードは個人アカウント専用です」と表示されます。このときコードは消費されないため、正しいコンテキストに切り替えればそのまま使用できます。

## 利用状況

「利用状況」タブでは組織の消費明細を確認できます。

- 期間は本日、直近 7 日間、直近 30 日間、または開始日と終了日のカスタム指定から選べます。
- 上部の 3 枚のカードには、選択した期間の消費総額、リクエスト数、Tokens が表示されます。
- その下には「メンバー別 / API キー別 / モデル別」の 3 つの軸でテーブルが表示され、リクエスト数、消費クレジット、入力と出力の Tokens が一覧されます。列見出しをクリックすると並べ替えできます。
- 軸の切り替えには「日付別」もあり、日次の推移グラフを表示します。リクエスト数、消費額、Tokens の 3 つの指標を切り替えられます。
- 「メンバー別」テーブルでメンバーをクリックすると、そのメンバーの API キー明細にドリルダウンできます。

一般メンバーが閲覧できる範囲は、組織設定の「メンバーが全員の利用状況を閲覧できる」スイッチによって決まります。有効な場合はメンバーも全員分の利用状況を閲覧でき、無効な場合は自分のデータのみとなり、このときメンバーのフィルターは表示されません。

組織コンテキストに切り替えると、「ダッシュボード」の組織利用状況パネルから「CSV をエクスポート」も利用でき、直近 7 日間の組織利用状況の集計を書き出せます。ログと利用状況の一般的な説明は [利用状況とログ](/ja/guide/usage) を参照してください。

## 組織設定

組織設定はユーザーメニューの「設定」ページにあります。組織グループは「一般」（組織情報）、「メンバー」、「予算」（組織の周期予算）、「危険な操作」に分かれ、いずれも管理者以上に表示されます。上部の組織セレクターで、自分が管理する組織を切り替えられます。組織の周期予算の使い方は上記の [組織の周期予算](#組織の周期予算) を参照してください。

### 組織情報

- **組織名**、**アバター URL**：切り替えメニューと概要ページに表示される情報です。
- **メンバーが全員の利用状況を閲覧できる**：有効にすると一般メンバーも全員分の利用状況を閲覧でき、無効にすると自分の分のみになります。未設定の場合はサイトの既定値に従います。
- **組織の API リクエストとレスポンスの本文を保存する**：組織 API キーによる呼び出しのリクエストとレスポンスの本文を保存するかどうかを決めるスイッチで、事後の調査に役立ちます。サイトが保存を許可していない場合は表示されません。

変更後は「保存」をクリックすると反映されます。

### 危険な操作

- **組織を退出**：どのメンバーも自分から退出でき、退出すると個人コンテキストに戻ります。**あなたの組織 API キーは無効化されます**。オーナーは先にオーナー権限を移譲しないと退出できません。一般メンバーには設定ページがないため、組織ページ「概要」タブ右上の「組織を退出」から操作してください。
- **オーナー権限の移譲**（オーナーのみ）：組織の管理者の中から新しいオーナーを 1 名選びます。移譲後、あなたは管理者に降格します。組織内にまだ管理者がいない場合は、先にいずれかのメンバーを管理者に昇格させる必要があります。
- **組織の解散**（オーナーのみ）：組織名を完全に一致させて入力しないと確定できません。解散すると組織とその API キーは無効化され、操作は元に戻せません。

## 監査ログ

「監査ログ」タブはオーナーと管理者のみ表示され、組織内の重要な操作を時系列の降順で記録します。時刻、操作者、アクション、詳細が含まれます。アクションのキーワードや操作者 ID で絞り込んで検索できます。メンバー管理、招待の処理、クレジットの振替とチャージ、組織の解散などの操作はすべて記録に残ります。

承認済み、拒否済み、取り消し済み、期限切れの招待は「招待」セグメントには表示されなくなりますが、監査ログでさかのぼって確認できます。
