# 常見問題

## 額度與計費

**額度是什麼？怎麼換算成錢？**

額度是站點內部的記賬單位，500,000 額度 = $1。介面上通常直接顯示美元金額。

**一次請求扣了多少，怎麼核對？**

按量付費的模型，花費 = 輸入 token × 輸入單價 + 輸出 token × 輸出單價，輸入和輸出各算各的；按次付費的模型調用成功即收取固定單次價格。在「日誌」頁展開某條記錄，可以看到本次的實際輸入價格、輸出價格、分組倍率和最終花費。完整規則見 [計費與價格](/hk/guide/billing)。

**帳戶額度足夠，為什麼提示額度不足？**

請檢查這把 API Key 自己的額度。API Key 額度與帳戶額度是分開計算的，API Key 額度只限制這一把密鑰的最大用量，兩者任意一方不足都會導致請求被拒。

**為什麼同一個模型，我看到的價格和別人不一樣？**

價格 = 模型單價 × 分組倍率，不同分組的倍率不同。在「可用模型」頁右上角切換分組，即可看到對應分組下的價格。

## 調用報錯

**提示無可用渠道？**

說明你當前分組下沒有能提供該模型的渠道。請到「可用模型」頁確認該模型在你的分組裏可用（開啟「只顯示可用」即可過濾），或在 API Key 設定裏切換到有該模型的分組。

**報錯「當前分組負載已飽和，請稍後再試」？**

上游返回了限流或暫時不可用，稍後重試即可。持續出現請聯繫站點管理員。

**第三方客戶端報錯 `Failed to fetch`？**

- 檢查介面地址與 API Key 是否填寫正確；
- 檢查是否啟用了 HTTPS，瀏覽器會攔截 HTTPS 頁面裏發出的 HTTP 請求；
- 部分客戶端需要把地址填到根域名，不要額外附加路徑。

**某個模型顯示「價格未配置」，能用嗎？**

不能保證。站點未給該模型配置價格時，調用可能會被直接拒絕，請改用價格頁上已標價的模型。

## 組織

**提示組織成員預算已超限？**

管理員為你設定了週期預算（每日 / 每週 / 每月）。本週期用量達到上限後，你的組織 API Key 會被拒絕，直到下個週期重置，或由管理員調高預算。當前已用量可在組織的「成員」頁查看。

**被移出組織後，我的 API Key 還能用嗎？**

不能。退出或被移出組織後，你在該組織下的 API Key 會被禁用；你的個人 API Key 與個人額度不受影響。

**個人額度可以轉給組織嗎？**

可以。在組織「概覽」頁點擊「轉入額度」，把個人額度單向轉入組織額度池。**轉入後不可撤回**，請確認金額後再提交。

**組織的消費怎麼看？**

組織的「用量」頁可以按成員、API Key、模型和日期查看消費明細；是否允許普通成員查看全員用量，由組織設定決定。
