# 計費與價格

本頁說明 Modeltaps 如何計算每一次請求的花費，以及你可以在哪些頁面上看到價格與賬單明細。

## 額度與金額

你的餘額以「額度」記賬，站點會按固定比例把額度換算成金額展示：**500,000 額度 = $1**。

介面上金額通常直接以美元顯示；如果站點關閉了貨幣顯示，則會顯示原始額度數字。價格頁裏的單價也支援在「$ / 1K tokens」與「$ / 1M tokens」之間切換。

## 在哪裏看價格

打開「可用模型」頁面，可以看到全部模型的輸入價格與輸出價格：

- **分組**：右上角切換分組，價格隨分組倍率變化，倍率會以 `x1`、`x0.5` 這樣的徽標標出，倍率為 0 的模型顯示「免費」。
- **只顯示可用**：預設開啟，只列出你當前分組能調用的模型。
- **類型**：區分「按量付費」和「按次付費」兩種計價方式。
- **單位**：在「顯示」菜單裏切換 K / M 單位。
- **查看詳情**：點擊行尾的眼睛圖標，可以看到該模型在各分組下的價格，以及快取、音頻、推理等擴展倍率。

如果某個模型顯示「價格未配置」，說明站點尚未為它設定價格，調用時可能被直接拒絕。

## 按量付費（tokens）

絕大多數對話與文本模型按 token 計費，輸入和輸出各自獨立計價：

> 本次花費 = 輸入 token 數 × 輸入單價 + 輸出 token 數 × 輸出單價

其中的單價就是價格頁上顯示的價格，也就是**模型單價 × 分組倍率**。輸入和輸出各用各的價格，不會再乘任何額外係數。

## 按次付費（times）

繪圖、音樂等模型按次計價：只要一次調用成功返回，就收取固定的單次價格，與消耗了多少 token 無關。這類模型在價格頁的「類型」列顯示為「按次付費」。

## 擴展倍率

有些用量屬於特殊類型的 token，例如命中快取的輸入、音頻、推理過程。它們會按各自的倍率折算後計入輸入側或輸出側：

| 名稱 | 計入側 | 含義 |
| --- | --- | --- |
| `cached_tokens` | 輸入 | 命中提示詞快取的輸入 token |
| `cached_write_tokens` | 輸入 | 寫入快取（5 分鐘有效期） |
| `cached_write_1h_tokens` | 輸入 | 寫入快取（1 小時有效期） |
| `cached_read_tokens` | 輸入 | 從快取讀取 |
| `openai_cache_write_tokens` | 輸入 | OpenAI 快取寫入 |
| `input_audio_tokens` | 輸入 | 音頻輸入 |
| `input_text_tokens` | 輸入 | 文本輸入 |
| `input_image_tokens` | 輸入 | 圖像輸入 |
| `output_audio_tokens` | 輸出 | 音頻輸出 |
| `output_image_tokens` | 輸出 | 圖像輸出 |
| `output_text_tokens` | 輸出 | 文本輸出 |
| `reasoning_tokens` | 輸出 | 推理過程消耗的 token |

倍率的含義很直接：**倍率為 1 表示與普通 token 同價，大於 1 表示更貴，小於 1 表示更便宜**。例如快取讀取的預設倍率是 0.1，命中快取的那部分輸入只按十分之一計價；1 小時有效期的快取寫入預設倍率是 2。

每個模型的實際倍率以「查看詳情」裏顯示的為準，未單獨配置的類型按普通 token 計價。

## 長上下文分檔

少數模型配置了長上下文分檔：當本次請求的輸入 token 超過設定閾值時，整次請求的輸入價與輸出價會各自乘上對應的分檔倍率。未超過閾值時價格不變。

## 預扣與結算

發起請求時，系統會按輸入 token 先預扣一部分額度；請求結束後按實際用量結算，多退少補。因此：

- 餘額或 API Key 額度不足時，請求會在發出前就被拒絕；
- 流式請求過程中如果額度耗盡，連接會被中斷；
- 日誌裏看到的花費是結算後的最終金額。

## 查看賬單明細

- 「用量」頁面：按時間、模型、API Key、應用維度看消費金額、Token 量和請求數。
- 「日誌」頁面：逐條請求的花費；展開某條記錄的詳情，可以看到本次的實際輸入價格、輸出價格、分組倍率、原始計費與最終花費，以及快取、推理等各類 token 的拆分。
- 「賬單」頁面的「帳戶流水」標籤（從側邊欄底部的用戶選單進入「賬單」）：充值、兌換、系統調整等賬務記錄，這些不在請求日誌裏。

兌換碼可能被限定用途：「僅個人」的碼只能兌入個人帳戶，「僅組織」的碼只能在組織上下文兌入組織額度池，用錯上下文會被拒絕且兌換碼保持可用，詳見 [組織](/hk/guide/organization)。
