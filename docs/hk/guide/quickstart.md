# 快速開始

本頁帶你在幾分鐘內完成第一次調用：登入 → 新建 API Key → 複製測試命令跑通 → 把地址和密鑰填進你自己的應用。

## 1. 登入並查看儀表板

用你的帳戶登入後，會先進入「儀表板」。這裏可以看到：

- 可用額度、今日請求數、今日消費與今日 Token 量；
- 近七日的用量趨勢與模型使用情況；
- 「當前可用模型」，即你當前分組下可以調用的模型清單；
- 「快速開始」卡片——點擊其中的聊天客戶端按鈕時，系統會自動為你創建一個聊天專用 API Key 並帶着密鑰打開該客戶端，適合先感受一下效果。

側邊欄底部的餘額行會顯示你的可用額度，點它就能進入「充值」。你所屬的分組決定了能路由到哪些渠道、以及每分鐘請求數上限。

## 2. 新建一個 API Key

正式接入請到「API Key」頁面自己建一個 API Key：

1. 點擊「新建 API Key」；
2. 填寫「名稱」（必填），用於日後在日誌和用量裏區分不同應用；
3. 「過期時間」預設「永不過期」，需要限期時關掉開關再選具體時間；
4. 「額度」留空表示不限額；填了數字表示該 API Key 最多只能消耗這麼多額度；
5. 「分組」可以指定這個 API Key 走哪個渠道分組，留空即使用你帳戶預設分組；
6. 提交。

更細的額度、週期重置、模型限制與 IP 白名單等設定見 [API Key 與額度](/hk/guide/tokens)。

::: tip API Key 額度與帳戶額度是兩回事
API Key 額度只限制這一把密鑰自己的最大用量，實際扣費仍受帳戶可用額度約束。兩者任意一方不足都會導致請求被拒。
:::

## 3. 用測試命令驗證

在「API Key」列表裏找到剛建的 API Key，打開它的「測試命令」。彈窗裏可以按協議切換 OpenAI / Claude / Gemini 標籤頁，選擇一個模型，Modeltaps 會把你的真實密鑰、站點地址和模型名拼成一條可直接運行的 `curl` 命令，點「複製命令」後黏貼到終端執行即可。

如果某個協議標籤頁提示暫無可用模型，說明你當前分組內沒有該類型的渠道，切回「OpenAI」標籤頁測試即可。

## 4. 接入你自己的應用

拿到 API Key 後，在你的應用裏做兩件事：

- 把 API 地址（Base URL）指向 Modeltaps 的站點地址；
- 把 API Key 換成 Modeltaps 生成的密鑰（形如 `sk-` 開頭的字符串）。

三套協議的具體地址與請求示例見 [API 接入](/hk/guide/api)。

## 5. 充值與兌換

需要補充額度時，點側邊欄底部的餘額行進入「充值」頁面：

- 「在線充值」：填寫充值金額，選擇支付方式後完成支付，頁面會顯示折扣後價格、手續費與實際支付金額；
- 「兌換碼充值」：把拿到的兌換碼黏貼到輸入框，點「兌換」即可入賬。

充值與邀請等賬務記錄不在請求日誌裏，請從側邊欄底部的用戶選單進入「賬單」頁面，在「帳戶流水」標籤查詢。

如果你和同事共用一份額度池，充值與額度也可以放到組織裏統一管理，見 [組織](/hk/guide/organization)。
