# 組織

組織讓你和同事共用一份額度池、共享 API Key 與用量視圖，同時按成員設定預算和可用模型。本頁介紹你在介面上能做的全部組織操作。

::: tip 是否能看到組織功能
組織功能由站點統一開啟。如果側邊欄頂部的身份卡片不能點開「切換上下文」菜單，說明當前站點沒有啟用該功能。
:::

## 個人上下文與組織上下文

側邊欄頂部的身份卡片就是上下文切換入口。點開後可以在「個人」與你所在的各個組織之間切換：

- **個人上下文**：使用你自己的額度和個人 API Key，卡片下半部分顯示個人餘額、用量進度與請求數。
- **組織上下文**：使用組織額度池，卡片顯示組織名稱、你的角色徽標、成員數，以及組織池餘額（僅所有者和管理員可見，成員會看到「餘額僅管理員可見」）。卡片上還有一行「本期預算」，顯示你本週期已用 / 上限與進度條，沒有為你設定預算時顯示「不限」；如果組織設了組織週期預算，所有者和管理員還會看到「組織預算」一行。

切換是全局的：切到某個組織後，你在「API Key」「用量」「充值」等頁面看到和創建的內容都屬於該組織。選擇會被記住，刷新頁面後仍停留在同一上下文。

在切換菜單裏選擇當前組織下方的「管理組織」，即可進入組織管理頁；也可以直接打開側邊欄的「組織」入口。

## 角色與權限

組織內有三種角色：

| 能力 | 成員 | 管理員 | 所有者 |
| --- | --- | --- | --- |
| 使用組織額度池調用模型 | ✅ | ✅ | ✅ |
| 創建與管理自己的組織 API Key | ✅ | ✅ | ✅ |
| 查看組織 API Key（全部） | — | ✅ | ✅ |
| 查看組織用量 | 自己的（受設定影響） | 全員 | 全員 |
| 邀請成員、代建成員帳戶 | — | ✅ | ✅ |
| 調整成員角色、移除成員 | — | ✅ | ✅ |
| 設定成員預算與模型白名單 | — | ✅ | ✅ |
| 修改組織資料與設定 | — | ✅ | ✅ |
| 組織充值、個人額度轉入 | — | ✅ | ✅ |
| 查看審計日誌 | — | ✅ | ✅ |
| 轉移所有權、解散組織 | — | — | ✅ |

管理員之間不能互相操作，你也不能對自己執行改角色或移除操作；介面隱藏了你無權使用的入口，伺服器端還會再校驗一次。

## 創建與加入組織

### 創建組織

在上下文切換菜單底部點「創建組織」，填寫組織名稱後提交。創建成功會自動切換到這個新組織，你就是它的所有者。每個帳戶可創建的組織數量由站點限制。

### 通過邀請加入

在個人上下文下打開「組織」頁面，會看到「我的邀請」：

- **定向邀請**：管理員按用戶名或郵箱指定了你，邀請會直接出現在列表裏，顯示邀請人和過期時間，點「接受」即可加入，點「拒絕」則作廢。
- **邀請鏈接**：把別人給你的邀請鏈接或邀請碼黏貼到「通過邀請鏈接加入組織」輸入框，點「加入」。

## 概覽

組織管理頁的「概覽」標籤顯示組織頭像、名稱與你的角色，下面是幾張卡片：

- **組織池餘額**：組織當前可用額度。僅所有者和管理員可見。
- **成員數**
- **組織本期預算**：本週期已用額度 / 上限，下方標註週期與下次重置時間；沒有設定組織預算時顯示「不限」。僅所有者和管理員可見。
- **創建時間**

所有者和管理員還能在餘額卡片上點「轉入額度」，把自己的個人額度轉入組織池。

::: warning 轉入不可撤回
個人額度轉入組織池是單向操作，轉移後無法退回個人帳戶。轉入前會顯示你的當前個人餘額，填寫的數量不能超過它。該功能可能被站點關閉。
:::

## 成員管理

成員管理在用戶選單的「設定」頁，組織分組下的「成員」裏：展示成員列表，包含用戶、角色、加入時間；管理員還能看到「預算」列和操作列。搜索框可按用戶名、顯示名稱或郵箱過濾當前頁。

管理員視圖頂部還有「成員 / 邀請」兩個分段，後者列出待處理的邀請。

### 邀請成員

點「邀請成員」，選擇一種方式：

- **定向邀請**：填寫郵箱或用戶名（二選一），對方會在自己的「我的邀請」裏確認，只能使用一次。
- **鏈接邀請**：生成一條邀請鏈接，創建後自動複製到剪貼板。可設定「最大使用次數」（填 0 表示不限），任何登入用戶都能憑鏈接加入。

兩種方式都可以指定加入後的角色（成員或管理員），並選擇永不過期或指定過期時間。

在「邀請」分段裏可以查看待處理邀請的被邀請人、角色、狀態、使用次數與過期時間，鏈接邀請可再次複製鏈接，任何待處理邀請都可以「撤銷」。

### 直接為他人建號

如果對方還沒有站點帳戶，管理員可以點「新建成員」，填寫用戶名、密碼（必填）以及顯示名稱、郵箱、角色，創建後該帳戶直接成為本組織成員。你選擇的角色不能高於自己的角色。建號後可以再為其設定預算，或為其創建組織 API Key。

### 調整角色與移除

在成員行的操作裏可以修改角色。移除成員需要二次確認，**被移除成員的組織 API Key 會被禁用**。

### 成員預算與模型白名單

點成員行上的預算值（或操作裏的「預算與白名單」）打開設定面板：

- **週期預算**：選擇「不限預算」，或按每日 / 每週 / 每月設定額度上限。設定後面板會顯示該成員本週期已用額度，列表裏以「已用 / 上限 · 週期」呈現，超限時標紅。
- **模型白名單**：勾選該成員可調用的模型。**留空表示沿用組織預設設定，即不額外限制。**

### 組織週期預算

除了逐個成員限額，管理員還可以為整個組織設一條合計上限：在「設定」頁組織分組的「預算」裏選擇「不限預算」，或按每日 / 每週 / 每月填寫額度上限，點「保存」生效。

- 組織預算統計的是**全體成員在該週期內的合計消費**。用盡後，組織內所有請求都會被拒絕，直到進入下一個週期。
- 兩層限額同時生效：一次請求先看你的成員預算，再看組織預算，兩者都還有餘量才會真正發給模型；任一層用盡都會被直接拒絕，且不產生費用。
- 修改預算週期會把本期已用額度清零重新計數；改回「不限預算」後就只保留各成員的預算約束。
- 已用情況可以在「概覽」標籤的「組織本期預算」卡片和側邊欄身份卡片上看到，兩處都只有所有者和管理員可見。

## 組織 API Key 與充值

切到組織上下文後，「API Key」頁面管理的就是組織 API Key：成員只能看到並管理自己創建的 API Key，所有者和管理員可以看到組織內全部 API Key。API Key 的創建方式與個人 API Key 一致，詳見 [API Key 與額度](/hk/guide/tokens)。

組織 API Key 消耗的是組織額度池，並受你的成員預算與模型白名單約束。

::: warning API Key 隨成員身份失效
成員被移除或主動退出組織後，其組織 API Key 會被禁用；組織被解散時，組織內 API Key 同樣失效。
:::

在組織上下文下，從側邊欄底部的餘額行打開「充值」頁面，頁面頂部會提示當前充值將進入組織額度池：

- 所有者和管理員可以進行在線充值和兌換碼充值，入賬全部進入組織池；
- 普通成員的側邊欄餘額行不顯示「充值」入口；若直接訪問充值頁地址（`/panel/topup`），也只會看到「組織充值僅限所有者和管理員操作」的提示。

兌換碼可能被限定用途：「不限」的碼個人與組織都能兌換，「僅組織」的碼只能在組織上下文兌入組織額度池，「僅個人」的碼只能兌入個人帳戶。用錯上下文時會提示「該兌換碼僅限組織帳戶使用」或「該兌換碼僅限個人帳戶使用」，此時兌換碼不會被消耗，切到正確的上下文後仍可繼續使用。

## 用量

「用量」標籤用於查看組織消費明細：

- 時間範圍可選今日、近 7 天、近 30 天或自定義起止日期；
- 頂部三張卡片顯示所選區間的消費總額、請求數與 Tokens；
- 下方按「按成員 / 按 API Key / 按模型」三個維度展示表格，列出請求數、消耗額度、輸入與輸出 Tokens，點擊列頭可排序；
- 維度切換裏還有「按日期」，展示按日趨勢圖，可在請求數、消費、Tokens 三個指標之間切換；
- 在「按成員」表格中點某位成員，可下鑽查看該成員的 API Key 明細。

普通成員能看到多少，取決於組織設定裏的「成員可見全員用量」開關：開啟時成員可查看全員用量，關閉時只能看到自己的數據，此時成員篩選器不會出現。

切到組織上下文後，「儀表板」上的組織用量面板還提供「導出 CSV」，導出近 7 天的組織用量聚合。日誌與用量的通用說明見 [用量與日誌](/hk/guide/usage)。

## 組織設定

組織設定在用戶選單的「設定」頁，組織分組下分為「通用」（組織資料）、「成員」、「預算」（組織週期預算）與「危險操作」，均管理員及以上可見；頂部的組織選擇器用於在你管理的多個組織之間切換。組織週期預算的用法見上文 [組織週期預算](#組織週期預算)。

### 組織資料

- **組織名稱**、**頭像 URL**：組織在切換菜單和概覽頁的展示資訊。
- **成員可見全員用量**：開啟後普通成員可查看全員用量，關閉則僅可見自己；未設定時沿用站點預設值。
- **留存組織 API 請求與回應內文**：開關，決定組織 API Key 調用的請求與回應內文是否留存，便於事後排查；站點未允許留存時不顯示該開關。

修改後點「保存」生效。

### 危險操作

- **退出組織**：任何成員都可以主動退出，退出後回到個人上下文，**你的組織 API Key 將被禁用**。所有者必須先轉移所有權才能退出。普通成員沒有設定頁入口，可在組織頁「概覽」標籤右上角點「退出組織」。
- **轉移所有權**（僅所有者）：從組織的管理員中選擇一位作為新所有者，轉移後你降級為管理員。若組織內還沒有管理員，需要先把某位成員提升為管理員。
- **解散組織**（僅所有者）：需要輸入組織名稱完全一致才能確認。解散後組織及其 API Key 被禁用，操作不可恢復。

## 審計日誌

「審計日誌」標籤僅所有者和管理員可見，按時間倒序記錄組織內的關鍵操作，包括時間、操作者、動作與詳情。可以按動作關鍵字或操作者 ID 過濾後查詢。成員管理、邀請處理、額度轉入與充值、組織解散等操作都會留下記錄。

已接受、已拒絕、已撤銷或已過期的邀請不再出現在「邀請」分段裏，可以到審計日誌中回溯。
