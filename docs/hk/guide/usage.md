# 用量與日誌

Modeltaps 提供三個層次的用量視圖：「儀表板」看當下概況，「用量」看趨勢與歸因，「日誌」逐條追查每一次請求。

## 儀表板

登入後的預設頁面，展示今日請求數、今日消費、今日 Token 量與可用額度，以及近七日趨勢、近七日模型使用情況、快取命中率與折扣節省等概覽資訊，並列出你當前可用的模型。

## 用量

「用量」頁面按時間維度呈現消費金額、Token 量與請求數的變化。

### 時間範圍

頂部的時間選擇器支援相對區間（最近 15 分鐘 / 30 分鐘 / 1 小時 / 3 小時 / 1 天 / 2 天 / 1 週 / 1 個月 / 1 年）、自然區間（今天、昨天、本週、上週、本月、上月、今年、去年）以及自定義範圍。預設展示最近 1 週。

### 指標卡

四張卡片分別展示消費金額、請求數、Token 量與快取命中率，每張卡帶一條迷你趨勢線，以及與上一週期相比的漲跌幅。

### 圖表

- **花費（$/日）**：逐日消費金額
- **請求數（次/日）**：逐日請求次數
- **Token 細分**：逐日輸入 / 輸出 Token
- **提示詞快取**：已快取與未快取 Token 的對比

### 歸因與篩選

頁面提供 Top 模型、Top API Keys、Top 應用三張排行卡，幫助你快速定位花費集中在哪裏。篩選條支援按模型、API Key 與應用多選過濾，圖表和排行會隨之聯動。

### 導出

點擊「導出 CSV」可把當前時間範圍與篩選條件下的數據導出為 CSV，包含日期、請求數、消費金額、輸入 Tokens 與輸出 Tokens；檔案帶 UTF-8 BOM，可直接用 Excel 打開。當前範圍沒有數據時會提示無可導出內容。

## 日誌

「日誌」頁面逐條記錄你的請求與消費。

頁面頂部有三個標籤：「請求日誌」「Midjourney」「非同步任務」，分別對應地址 `?tab=log`、`?tab=midjourney`、`?tab=task`，可以直接收藏或分享；預設停留在「請求日誌」。組織上下文下只有「請求日誌」，另外兩個標籤不顯示。下面說明的都是「請求日誌」標籤。

### 直方圖

列表上方的「請求量」直方圖按時間聚合展示請求數、花費與 Tokens，可以展開或收起。

### 列

預設列包括時間、分組、API Key、應用、類型、模型、模態、狀態（結束原因）、耗時、吞吐、輸入、輸出、花費等。右上角「列設定」可自由顯示 / 隱藏列。

其中：

- **模態** 表示這次調用屬於哪類介面，如對話、補全、Responses、向量化、重排序、內容審核、圖片生成 / 編輯 / 變體、語音合成 / 轉寫 / 翻譯、實時、視頻。
- **狀態（結束原因）** 表示這次生成為何結束：已完成、長度截斷、內容過濾、工具調用或錯誤。
- **耗時** 中的 `t/s` 是輸出 Token 數除以總生成時間，代表生成速度。

### 篩選

篩選條支援多個維度，其中枚舉類欄目既能勾選也能排除：

- API Key 名稱、模型、應用（可從預置項勾選，也可直接輸入自定義值）
- 結束原因、模態
- 最低消費（額度）、最低 Token 數
- 請求 ID（本站追蹤 ID，精確匹配）

時間範圍選擇器與「用量」頁一致。「刷新/清除搜索條件」按鈕可一鍵復位。

### 單條明細

點擊任意一行可以展開該請求的明細，包括概覽、請求維度資訊（應用、API Key、請求 ID、上游請求 ID、結束原因、是否流式）以及消費明細。消費明細會拆出各類 Token 的計費構成（輸入 / 輸出文本、音頻、圖像、推理、快取讀寫等）與對應倍率，並展示分組倍率、實際輸入 / 輸出價格、原始計費與實際計費，計價方式區分「按 Token」與「按次」。

如果站點與帳戶開啟了完整請求 / 響應留存，明細裏還能查看這次調用的請求體與響應體；未開啟、已超出保留期或無權查看時，會給出相應說明。留存開關只對開啟之後的新請求生效，歷史請求不會補錄。

### 按 ID 查找

在「更多操作」中選擇「按 ID 查找」，黏貼日誌 ID 即可精確定位單條並直接打開明細。

### 導出

「更多操作」中的「導出 CSV」會按當前篩選條件導出日誌。

## 賬務記錄

充值、邀請等賬務記錄不在請求日誌裏，入口在側邊欄底部用戶選單的「賬單」頁面：

- **帳戶流水**標籤：查看餘額變動與交易明細；
- **月度賬單**標籤：查看並下載按月匯總的賬單。
