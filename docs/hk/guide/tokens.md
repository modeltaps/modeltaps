# API Key 與額度

API Key 就是你調用 Modeltaps 時使用的密鑰。建議按應用、按環境分別建立 API Key，這樣在日誌與用量裏能清楚區分是誰在花錢，出問題時也能單獨停用一把密鑰而不影響其他應用。

## API Key 列表

「API Key」頁面以列表形式展示你的全部 API Key，預設可見的列包括：

| 列 | 含義 |
| --- | --- |
| API Key | 名稱與密鑰（密鑰預設遮蓋，可展開查看或複製） |
| 分組 | 該 API Key 使用的渠道分組；未指定時顯示「跟隨用戶」 |
| 過期時間 | 「永不」、剩餘時間或「已過期」 |
| 最近使用 | 上次成功調用的時間，從未調用則顯示「從未使用」 |
| 用量 | 累計已用額度，並附帶「今日」已用 |
| 限額 | 剩餘額度或「未限額」；設了週期時顯示本週期上限與下次重置時間 |
| 狀態 | 開關，可直接啟用 / 停用該 API Key |

右上角的「列設定」可以顯示或隱藏列（例如預設隱藏的「創建時間」）。頂部篩選條支援按 API Key 名稱搜索。

每行的操作菜單提供：複製密鑰、在聊天客戶端中打開、「測試命令」、「接入 OpenClaw」、跳轉到該 API Key 的「用量」和「日誌」、編輯與刪除。

## 新建與編輯 API Key

點擊「新建 API Key」打開編輯面板，分為幾個區塊。

### 基本資料

- **名稱**（必填）：日誌與用量分析都按 API Key 名稱聚合，改名後歷史記錄不會跟着改，建議一次定好。
- **永不過期 / 過期時間**：預設永不過期；關掉開關後可以指定一個具體的到期時刻，過期後該 API Key 不再可用。

### 額度與週期

這裏只有一個額度輸入框，含義隨「重置週期」變化：

- **不填額度、不選週期**：不限額。該 API Key 本身不設上限，實際消費仍受帳戶可用額度約束。
- **填了額度、不選週期**：總額限制。累計消費達到該額度後 API Key 即停用。
- **填了額度並選擇週期**（每日 / 每週 / 每月）：額度變成「每週期額度上限」。每到週期邊界的 0 點自動重置，不額外扣減你的帳戶餘額。選擇週期時額度必須大於 0。

面板會提示當前站點用於重置的時區與每週起點（週一或週日）。列表的「限額」列會顯示下次重置時間。

::: warning 額度是兩層
API Key 額度只限制 API Key 自身的最大使用量，真正扣的是帳戶額度。帳戶額度不足時，即使 API Key 未限額也會請求失敗；反過來 API Key 額度用盡時，帳戶再有錢也會被攔下。
:::

### 渠道分組

- **分組**：指定該 API Key 請求走哪個渠道分組，留空則跟隨你的帳戶分組。
- **備用分組**：當主分組不可用時，請求會改走備用分組。

如果分組已被刪除或你無權使用，列表中的分組標籤會以醒目顏色提示。

### 高級設定

- **模型限制**：開啟後可以勾選允許這把 API Key 使用的模型；不勾選任何模型即代表允許全部模型。適合把某個應用限制在少數幾個模型上。
- **IP 白名單**：開啟後每行填一個 IP 或 CIDR 段（如 `192.168.1.1`、`10.0.0.0/8`），只有來自這些地址的請求才會被放行。
- **心跳設定（實驗性）**：當請求長時間沒有返回數據時，客戶端可能因超時斷開。開啟後，超過你設定的等待秒數仍無響應時，Modeltaps 會每 5 秒發送一次心跳（非流式返回空行，流式返回 `::PING`）以保持連接。等待時間可設 30～90 秒。若你的請求經過中轉程序，不建議開啟。

## 測試 API Key

在操作菜單裏選擇「測試命令」，彈窗會按 OpenAI / Claude / Gemini 三個標籤頁給出可直接運行的 `curl`：命令中已經填好你的真實密鑰、站點地址和所選模型，複製到終端執行即可確認 API Key 可用。模型可以在下拉框中搜索切換。

若某個協議提示「該協議下暫無可用模型」，說明當前分組內沒有對應類型的渠道，該協議暫時用不了，可改用 OpenAI 標籤頁測試。

## 停用與刪除

- 列表中的狀態開關可以隨時停用 / 恢復一把 API Key，已停用的 API Key 調用會直接被拒。
- 「刪除」不可恢復，刪除前請確認沒有線上應用還在使用這把密鑰。

## 補充額度

帳戶額度在「充值」頁面補充（入口在側邊欄底部的餘額行），支援在線支付與兌換碼兩種方式；充值記錄請到用戶選單裏的「賬單」頁面、「帳戶流水」標籤查看。詳見 [快速開始](/hk/guide/quickstart) 中的說明。

切換到組織後，這裏管理的是組織 API Key，額度來自組織額度池，還可以按成員設定週期預算，詳見 [組織](/hk/guide/organization)。
