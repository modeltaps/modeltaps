# API Key 与额度

API Key 就是你调用 Modeltaps 时使用的密钥。建议按应用、按环境分别建立 API Key，这样在日志与用量里能清楚区分是谁在花钱，出问题时也能单独停用一把密钥而不影响其他应用。

## API Key 列表

「API Key」页面以列表形式展示你的全部 API Key，默认可见的列包括：

| 列 | 含义 |
| --- | --- |
| API Key | 名称与密钥（密钥默认遮盖，可展开查看或复制） |
| 分组 | 该 API Key 使用的渠道分组；未指定时显示「跟随用户」 |
| 过期时间 | 「永不」、剩余时间或「已过期」 |
| 最近使用 | 上次成功调用的时间，从未调用则显示「从未使用」 |
| 用量 | 累计已用额度，并附带「今日」已用 |
| 限额 | 剩余额度或「未限额」；设了周期时显示本周期上限与下次重置时间 |
| 状态 | 开关，可直接启用 / 停用该 API Key |

右上角的「列设置」可以显示或隐藏列（例如默认隐藏的「创建时间」）。顶部筛选条支持按 API Key 名称搜索。

每行的操作菜单提供：复制密钥、在聊天客户端中打开、「测试命令」、「接入 OpenClaw」、跳转到该 API Key 的「用量」和「日志」、编辑与删除。

## 新建与编辑 API Key

点击「新建 API Key」打开编辑面板，分为几个区块。

### 基本信息

- **名称**（必填）：日志与用量分析都按 API Key 名称聚合，改名后历史记录不会跟着改，建议一次定好。
- **永不过期 / 过期时间**：默认永不过期；关掉开关后可以指定一个具体的到期时刻，过期后该 API Key 不再可用。

### 额度与周期

这里只有一个额度输入框，含义随「重置周期」变化：

- **不填额度、不选周期**：不限额。该 API Key 本身不设上限，实际消费仍受账户可用额度约束。
- **填了额度、不选周期**：总额限制。累计消费达到该额度后 API Key 即停用。
- **填了额度并选择周期**（每日 / 每周 / 每月）：额度变成「每周期额度上限」。每到周期边界的 0 点自动重置，不额外扣减你的账户余额。选择周期时额度必须大于 0。

面板会提示当前站点用于重置的时区与每周起点（周一或周日）。列表的「限额」列会显示下次重置时间。

::: warning 额度是两层
API Key 额度只限制 API Key 自身的最大使用量，真正扣的是账户额度。账户额度不足时，即使 API Key 未限额也会请求失败；反过来 API Key 额度用尽时，账户再有钱也会被拦下。
:::

### 渠道分组

- **分组**：指定该 API Key 请求走哪个渠道分组，留空则跟随你的账号分组。
- **备用分组**：当主分组不可用时，请求会改走备用分组。

如果分组已被删除或你无权使用，列表中的分组标签会以醒目颜色提示。

### 高级设置

- **模型限制**：开启后可以勾选允许这把 API Key 使用的模型；不勾选任何模型即代表允许全部模型。适合把某个应用限制在少数几个模型上。
- **IP 白名单**：开启后每行填一个 IP 或 CIDR 段（如 `192.168.1.1`、`10.0.0.0/8`），只有来自这些地址的请求才会被放行。
- **心跳设置（实验性）**：当请求长时间没有返回数据时，客户端可能因超时断开。开启后，超过你设置的等待秒数仍无响应时，Modeltaps 会每 5 秒发送一次心跳（非流式返回空行，流式返回 `::PING`）以保持连接。等待时间可设 30～90 秒。若你的请求经过中转程序，不建议开启。

## 测试 API Key

在操作菜单里选择「测试命令」，弹窗会按 OpenAI / Claude / Gemini 三个标签页给出可直接运行的 `curl`：命令中已经填好你的真实密钥、站点地址和所选模型，复制到终端执行即可确认 API Key 可用。模型可以在下拉框中搜索切换。

若某个协议提示「该协议下暂无可用模型」，说明当前分组内没有对应类型的渠道，该协议暂时用不了，可改用 OpenAI 标签页测试。

## 停用与删除

- 列表中的状态开关可以随时停用 / 恢复一把 API Key，已停用的 API Key 调用会直接被拒。
- 「删除」不可恢复，删除前请确认没有线上应用还在使用这把密钥。

## 补充额度

账户额度在「充值」页面补充（入口在侧边栏底部的余额行），支持在线支付与兑换码两种方式；充值记录请到用户菜单里的「账单」页面、「账户流水」标签查看。详见 [快速开始](/zh/guide/quickstart) 中的说明。

切换到组织后，这里管理的是组织 API Key，额度来自组织额度池，还可以按成员设置周期预算，详见 [组织](/zh/guide/organization)。
