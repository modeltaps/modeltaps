# 组织

组织让你和同事共用一份额度池、共享 API Key 与用量视图，同时按成员设定预算和可用模型。本页介绍你在界面上能做的全部组织操作。

::: tip 是否能看到组织功能
组织功能由站点统一开启。如果侧边栏顶部的身份卡片不能点开「切换上下文」菜单，说明当前站点没有启用该功能。
:::

## 个人上下文与组织上下文

侧边栏顶部的身份卡片就是上下文切换入口。点开后可以在「个人」与你所在的各个组织之间切换：

- **个人上下文**：使用你自己的额度和个人 API Key，卡片下半部分显示个人余额、用量进度与请求数。
- **组织上下文**：使用组织额度池，卡片显示组织名称、你的角色徽标、成员数，以及组织池余额（仅所有者和管理员可见，成员会看到「余额仅管理员可见」）。卡片上还有一行「本期预算」，显示你本周期已用 / 上限与进度条，没有为你设置预算时显示「不限」；如果组织设了组织周期预算，所有者和管理员还会看到「组织预算」一行。

切换是全局的：切到某个组织后，你在「API Key」「用量」「充值」等页面看到和创建的内容都属于该组织。选择会被记住，刷新页面后仍停留在同一上下文。

在切换菜单里选择当前组织下方的「管理组织」，即可进入组织管理页；也可以直接打开侧边栏的「组织」入口。

## 角色与权限

组织内有三种角色：

| 能力 | 成员 | 管理员 | 所有者 |
| --- | --- | --- | --- |
| 使用组织额度池调用模型 | ✅ | ✅ | ✅ |
| 创建与管理自己的组织 API Key | ✅ | ✅ | ✅ |
| 查看组织 API Key（全部） | — | ✅ | ✅ |
| 查看组织用量 | 自己的（受设置影响） | 全员 | 全员 |
| 邀请成员、代建成员账号 | — | ✅ | ✅ |
| 调整成员角色、移除成员 | — | ✅ | ✅ |
| 设置成员预算与模型白名单 | — | ✅ | ✅ |
| 修改组织资料与设置 | — | ✅ | ✅ |
| 组织充值、个人额度转入 | — | ✅ | ✅ |
| 查看审计日志 | — | ✅ | ✅ |
| 转移所有权、解散组织 | — | — | ✅ |

管理员之间不能互相操作，你也不能对自己执行改角色或移除操作；界面隐藏了你无权使用的入口，服务端还会再校验一次。

## 创建与加入组织

### 创建组织

在上下文切换菜单底部点「创建组织」，填写组织名称后提交。创建成功会自动切换到这个新组织，你就是它的所有者。每个账号可创建的组织数量由站点限制。

### 通过邀请加入

在个人上下文下打开「组织」页面，会看到「我的邀请」：

- **定向邀请**：管理员按用户名或邮箱指定了你，邀请会直接出现在列表里，显示邀请人和过期时间，点「接受」即可加入，点「拒绝」则作废。
- **邀请链接**：把别人给你的邀请链接或邀请码粘贴到「通过邀请链接加入组织」输入框，点「加入」。

## 概览

组织管理页的「概览」标签显示组织头像、名称与你的角色，下面是几张卡片：

- **组织池余额**：组织当前可用额度。仅所有者和管理员可见。
- **成员数**
- **组织本期预算**：本周期已用额度 / 上限，下方标注周期与下次重置时间；没有设置组织预算时显示「不限」。仅所有者和管理员可见。
- **创建时间**

所有者和管理员还能在余额卡片上点「转入额度」，把自己的个人额度转入组织池。

::: warning 转入不可撤回
个人额度转入组织池是单向操作，转移后无法退回个人账户。转入前会显示你的当前个人余额，填写的数量不能超过它。该功能可能被站点关闭。
:::

## 成员管理

成员管理在用户菜单的「设置」页，组织分组下的「成员」里：展示成员列表，包含用户、角色、加入时间；管理员还能看到「预算」列和操作列。搜索框可按用户名、显示名称或邮箱过滤当前页。

管理员视图顶部还有「成员 / 邀请」两个分段，后者列出待处理的邀请。

### 邀请成员

点「邀请成员」，选择一种方式：

- **定向邀请**：填写邮箱或用户名（二选一），对方会在自己的「我的邀请」里确认，只能使用一次。
- **链接邀请**：生成一条邀请链接，创建后自动复制到剪贴板。可设置「最大使用次数」（填 0 表示不限），任何登录用户都能凭链接加入。

两种方式都可以指定加入后的角色（成员或管理员），并选择永不过期或指定过期时间。

在「邀请」分段里可以查看待处理邀请的被邀请人、角色、状态、使用次数与过期时间，链接邀请可再次复制链接，任何待处理邀请都可以「撤销」。

### 直接为他人建号

如果对方还没有站点账号，管理员可以点「新建成员」，填写用户名、密码（必填）以及显示名称、邮箱、角色，创建后该账号直接成为本组织成员。你选择的角色不能高于自己的角色。建号后可以再为其设置预算，或为其创建组织 API Key。

### 调整角色与移除

在成员行的操作里可以修改角色。移除成员需要二次确认，**被移除成员的组织 API Key 会被禁用**。

### 成员预算与模型白名单

点成员行上的预算值（或操作里的「预算与白名单」）打开设置面板：

- **周期预算**：选择「不限预算」，或按每日 / 每周 / 每月设定额度上限。设定后面板会显示该成员本周期已用额度，列表里以「已用 / 上限 · 周期」呈现，超限时标红。
- **模型白名单**：勾选该成员可调用的模型。**留空表示沿用组织默认设置，即不额外限制。**

### 组织周期预算

除了逐个成员限额，管理员还可以为整个组织设一条合计上限：在「设置」页组织分组的「预算」里选择「不限预算」，或按每日 / 每周 / 每月填写额度上限，点「保存」生效。

- 组织预算统计的是**全体成员在该周期内的合计消费**。用尽后，组织内所有请求都会被拒绝，直到进入下一个周期。
- 两层限额同时生效：一次请求先看你的成员预算，再看组织预算，两者都还有余量才会真正发给模型；任一层用尽都会被直接拒绝，且不产生费用。
- 修改预算周期会把本期已用额度清零重新计数；改回「不限预算」后就只保留各成员的预算约束。
- 已用情况可以在「概览」标签的「组织本期预算」卡片和侧边栏身份卡片上看到，两处都只有所有者和管理员可见。

## 组织 API Key 与充值

切到组织上下文后，「API Key」页面管理的就是组织 API Key：成员只能看到并管理自己创建的 API Key，所有者和管理员可以看到组织内全部 API Key。API Key 的创建方式与个人 API Key 一致，详见 [API Key 与额度](/zh/guide/tokens)。

组织 API Key 消耗的是组织额度池，并受你的成员预算与模型白名单约束。

::: warning API Key 随成员身份失效
成员被移除或主动退出组织后，其组织 API Key 会被禁用；组织被解散时，组织内 API Key 同样失效。
:::

在组织上下文下，从侧边栏底部的余额行打开「充值」页面，页面顶部会提示当前充值将进入组织额度池：

- 所有者和管理员可以进行在线充值和兑换码充值，入账全部进入组织池；
- 普通成员的侧边栏余额行不显示「充值」入口；若直接访问充值页地址（`/panel/topup`），也只会看到「组织充值仅限所有者和管理员操作」的提示。

兑换码可能被限定用途：「不限」的码个人与组织都能兑换，「仅组织」的码只能在组织上下文兑入组织额度池，「仅个人」的码只能兑入个人账户。用错上下文时会提示「该兑换码仅限组织账户使用」或「该兑换码仅限个人账户使用」，此时兑换码不会被消耗，切到正确的上下文后仍可继续使用。

## 用量

「用量」标签用于查看组织消费明细：

- 时间范围可选今日、近 7 天、近 30 天或自定义起止日期；
- 顶部三张卡片显示所选区间的消费总额、请求数与 Tokens；
- 下方按「按成员 / 按 API Key / 按模型」三个维度展示表格，列出请求数、消耗额度、输入与输出 Tokens，点击列头可排序；
- 维度切换里还有「按日期」，展示按日趋势图，可在请求数、消费、Tokens 三个指标之间切换；
- 在「按成员」表格中点某位成员，可下钻查看该成员的 API Key 明细。

普通成员能看到多少，取决于组织设置里的「成员可见全员用量」开关：开启时成员可查看全员用量，关闭时只能看到自己的数据，此时成员筛选器不会出现。

切到组织上下文后，「仪表盘」上的组织用量面板还提供「导出 CSV」，导出近 7 天的组织用量聚合。日志与用量的通用说明见 [用量与日志](/zh/guide/usage)。

## 组织设置

组织设置在用户菜单的「设置」页，组织分组下分为「通用」（组织资料）、「成员」、「预算」（组织周期预算）与「危险操作」，均管理员及以上可见；顶部的组织选择器用于在你管理的多个组织之间切换。组织周期预算的用法见上文 [组织周期预算](#组织周期预算)。

### 组织资料

- **组织名称**、**头像 URL**：组织在切换菜单和概览页的展示信息。
- **成员可见全员用量**：开启后普通成员可查看全员用量，关闭则仅可见自己；未设置时沿用站点默认值。
- **留存组织 API 请求与响应正文**：开关，决定组织 API Key 调用的请求与响应正文是否留存，便于事后排查；站点未允许留存时不显示该开关。

修改后点「保存」生效。

### 危险操作

- **退出组织**：任何成员都可以主动退出，退出后回到个人上下文，**你的组织 API Key 将被禁用**。所有者必须先转移所有权才能退出。普通成员没有设置页入口，可在组织页「概览」标签右上角点「退出组织」。
- **转移所有权**（仅所有者）：从组织的管理员中选择一位作为新所有者，转移后你降级为管理员。若组织内还没有管理员，需要先把某位成员提升为管理员。
- **解散组织**（仅所有者）：需要输入组织名称完全一致才能确认。解散后组织及其 API Key 被禁用，操作不可恢复。

## 审计日志

「审计日志」标签仅所有者和管理员可见，按时间倒序记录组织内的关键操作，包括时间、操作者、动作与详情。可以按动作关键字或操作者 ID 过滤后查询。成员管理、邀请处理、额度转入与充值、组织解散等操作都会留下记录。

已接受、已拒绝、已撤销或已过期的邀请不再出现在「邀请」分段里，可以到审计日志中回溯。
