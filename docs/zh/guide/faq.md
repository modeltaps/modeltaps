# 常见问题

## 额度与计费

**额度是什么？怎么换算成钱？**

额度是站点内部的记账单位，500,000 额度 = $1。界面上通常直接显示美元金额。

**一次请求扣了多少，怎么核对？**

按量付费的模型，花费 = 输入 token × 输入单价 + 输出 token × 输出单价，输入和输出各算各的；按次付费的模型调用成功即收取固定单次价格。在「日志」页展开某条记录，可以看到本次的实际输入价格、输出价格、分组倍率和最终花费。完整规则见 [计费与价格](/zh/guide/billing)。

**账户额度足够，为什么提示额度不足？**

请检查这把 API Key 自己的额度。API Key 额度与账户额度是分开计算的，API Key 额度只限制这一把密钥的最大用量，两者任意一方不足都会导致请求被拒。

**为什么同一个模型，我看到的价格和别人不一样？**

价格 = 模型单价 × 分组倍率，不同分组的倍率不同。在「可用模型」页右上角切换分组，即可看到对应分组下的价格。

## 调用报错

**提示无可用渠道？**

说明你当前分组下没有能提供该模型的渠道。请到「可用模型」页确认该模型在你的分组里可用（开启「只显示可用」即可过滤），或在 API Key 设置里切换到有该模型的分组。

**报错「当前分组负载已饱和，请稍后再试」？**

上游返回了限流或暂时不可用，稍后重试即可。持续出现请联系站点管理员。

**第三方客户端报错 `Failed to fetch`？**

- 检查接口地址与 API Key 是否填写正确；
- 检查是否启用了 HTTPS，浏览器会拦截 HTTPS 页面里发出的 HTTP 请求；
- 部分客户端需要把地址填到根域名，不要额外附加路径。

**某个模型显示「价格未配置」，能用吗？**

不能保证。站点未给该模型配置价格时，调用可能会被直接拒绝，请改用价格页上已标价的模型。

## 组织

**提示组织成员预算已超限？**

管理员为你设置了周期预算（每日 / 每周 / 每月）。本周期用量达到上限后，你的组织 API Key 会被拒绝，直到下个周期重置，或由管理员调高预算。当前已用量可在组织的「成员」页查看。

**被移出组织后，我的 API Key 还能用吗？**

不能。退出或被移出组织后，你在该组织下的 API Key 会被禁用；你的个人 API Key 与个人额度不受影响。

**个人额度可以转给组织吗？**

可以。在组织「概览」页点击「转入额度」，把个人额度单向转入组织额度池。**转入后不可撤回**，请确认金额后再提交。

**组织的消费怎么看？**

组织的「用量」页可以按成员、API Key、模型和日期查看消费明细；是否允许普通成员查看全员用量，由组织设置决定。
