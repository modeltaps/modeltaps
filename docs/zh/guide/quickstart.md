# 快速开始

本页带你在几分钟内完成第一次调用：登录 → 新建 API Key → 复制测试命令跑通 → 把地址和密钥填进你自己的应用。

## 1. 登录并查看仪表盘

用你的账号登录后，会先进入「仪表盘」。这里可以看到：

- 可用额度、今日请求数、今日消费与今日 Token 量；
- 近七日的用量趋势与模型使用情况；
- 「当前可用模型」，即你当前分组下可以调用的模型清单；
- 「快速开始」卡片——点击其中的聊天客户端按钮时，系统会自动为你创建一个聊天专用 API Key 并带着密钥打开该客户端，适合先感受一下效果。

侧边栏底部的余额行会显示你的可用额度，点它就能进入「充值」。你所属的分组决定了能路由到哪些渠道、以及每分钟请求数上限。

## 2. 新建一个 API Key

正式接入请到「API Key」页面自己建一个 API Key：

1. 点击「新建 API Key」；
2. 填写「名称」（必填），用于日后在日志和用量里区分不同应用；
3. 「过期时间」默认「永不过期」，需要限期时关掉开关再选具体时间；
4. 「额度」留空表示不限额；填了数字表示该 API Key 最多只能消耗这么多额度；
5. 「分组」可以指定这个 API Key 走哪个渠道分组，留空即使用你账号默认分组；
6. 提交。

更细的额度、周期重置、模型限制与 IP 白名单等设置见 [API Key 与额度](/zh/guide/tokens)。

::: tip API Key 额度与账户额度是两回事
API Key 额度只限制这一把密钥自己的最大用量，实际扣费仍受账户可用额度约束。两者任意一方不足都会导致请求被拒。
:::

## 3. 用测试命令验证

在「API Key」列表里找到刚建的 API Key，打开它的「测试命令」。弹窗里可以按协议切换 OpenAI / Claude / Gemini 标签页，选择一个模型，Modeltaps 会把你的真实密钥、站点地址和模型名拼成一条可直接运行的 `curl` 命令，点「复制命令」后粘贴到终端执行即可。

如果某个协议标签页提示暂无可用模型，说明你当前分组内没有该类型的渠道，切回「OpenAI」标签页测试即可。

## 4. 接入你自己的应用

拿到 API Key 后，在你的应用里做两件事：

- 把 API 地址（Base URL）指向 Modeltaps 的站点地址；
- 把 API Key 换成 Modeltaps 生成的密钥（形如 `sk-` 开头的字符串）。

三套协议的具体地址与请求示例见 [API 接入](/zh/guide/api)。

## 5. 充值与兑换

需要补充额度时，点侧边栏底部的余额行进入「充值」页面：

- 「在线充值」：填写充值金额，选择支付方式后完成支付，页面会显示折扣后价格、手续费与实际支付金额；
- 「兑换码充值」：把拿到的兑换码粘贴到输入框，点「兑换」即可入账。

充值与邀请等账务记录不在请求日志里，请从侧边栏底部的用户菜单进入「账单」页面，在「账户流水」标签查询。

如果你和同事共用一份额度池，充值与额度也可以放到组织里统一管理，见 [组织](/zh/guide/organization)。
