# 用量与日志

Modeltaps 提供三个层次的用量视图：「仪表盘」看当下概况，「用量」看趋势与归因，「日志」逐条追查每一次请求。

## 仪表盘

登录后的默认页面，展示今日请求数、今日消费、今日 Token 量与可用额度，以及近七日趋势、近七日模型使用情况、缓存命中率与折扣节省等概览信息，并列出你当前可用的模型。

## 用量

「用量」页面按时间维度呈现消费金额、Token 量与请求数的变化。

### 时间范围

顶部的时间选择器支持相对区间（最近 15 分钟 / 30 分钟 / 1 小时 / 3 小时 / 1 天 / 2 天 / 1 周 / 1 个月 / 1 年）、自然区间（今天、昨天、本周、上周、本月、上月、今年、去年）以及自定义范围。默认展示最近 1 周。

### 指标卡

四张卡片分别展示消费金额、请求数、Token 量与缓存命中率，每张卡带一条迷你趋势线，以及与上一周期相比的涨跌幅。

### 图表

- **花费（$/日）**：逐日消费金额
- **请求数（次/日）**：逐日请求次数
- **Token 细分**：逐日输入 / 输出 Token
- **提示词缓存**：已缓存与未缓存 Token 的对比

### 归因与筛选

页面提供 Top 模型、Top API Keys、Top 应用三张排行卡，帮助你快速定位花费集中在哪里。筛选条支持按模型、API Key 与应用多选过滤，图表和排行会随之联动。

### 导出

点击「导出 CSV」可把当前时间范围与筛选条件下的数据导出为 CSV，包含日期、请求数、消费金额、输入 Tokens 与输出 Tokens；文件带 UTF-8 BOM，可直接用 Excel 打开。当前范围没有数据时会提示无可导出内容。

## 日志

「日志」页面逐条记录你的请求与消费。

页面顶部有三个标签：「请求日志」「Midjourney」「异步任务」，分别对应地址 `?tab=log`、`?tab=midjourney`、`?tab=task`，可以直接收藏或分享；默认停留在「请求日志」。组织上下文下只有「请求日志」，另外两个标签不显示。下面说明的都是「请求日志」标签。

### 直方图

列表上方的「请求量」直方图按时间聚合展示请求数、花费与 Tokens，可以展开或收起。

### 列

默认列包括时间、分组、API Key、应用、类型、模型、模态、状态（结束原因）、耗时、吞吐、输入、输出、花费等。右上角「列设置」可自由显示 / 隐藏列。

其中：

- **模态** 表示这次调用属于哪类接口，如对话、补全、Responses、向量化、重排序、内容审核、图片生成 / 编辑 / 变体、语音合成 / 转写 / 翻译、实时、视频。
- **状态（结束原因）** 表示这次生成为何结束：已完成、长度截断、内容过滤、工具调用或错误。
- **耗时** 中的 `t/s` 是输出 Token 数除以总生成时间，代表生成速度。

### 筛选

筛选条支持多个维度，其中枚举类字段既能勾选也能排除：

- API Key 名称、模型、应用（可从预置项勾选，也可直接输入自定义值）
- 结束原因、模态
- 最低消费（额度）、最低 Token 数
- 请求 ID（本站追踪 ID，精确匹配）

时间范围选择器与「用量」页一致。「刷新/清除搜索条件」按钮可一键复位。

### 单条明细

点击任意一行可以展开该请求的明细，包括概览、请求维度信息（应用、API Key、请求 ID、上游请求 ID、结束原因、是否流式）以及消费明细。消费明细会拆出各类 Token 的计费构成（输入 / 输出文本、音频、图像、推理、缓存读写等）与对应倍率，并展示分组倍率、实际输入 / 输出价格、原始计费与实际计费，计价方式区分「按 Token」与「按次」。

如果站点与账户开启了完整请求 / 响应留存，明细里还能查看这次调用的请求体与响应体；未开启、已超出保留期或无权查看时，会给出相应说明。留存开关只对开启之后的新请求生效，历史请求不会补录。

### 按 ID 查找

在「更多操作」中选择「按 ID 查找」，粘贴日志 ID 即可精确定位单条并直接打开明细。

### 导出

「更多操作」中的「导出 CSV」会按当前筛选条件导出日志。

## 账务记录

充值、邀请等账务记录不在请求日志里，入口在侧边栏底部用户菜单的「账单」页面：

- **账户流水**标签：查看余额变动与交易明细；
- **月度账单**标签：查看并下载按月汇总的账单。
