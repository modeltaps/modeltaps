# 计费与价格

本页说明 Modeltaps 如何计算每一次请求的花费，以及你可以在哪些页面上看到价格与账单明细。

## 额度与金额

你的余额以「额度」记账，站点会按固定比例把额度换算成金额展示：**500,000 额度 = $1**。

界面上金额通常直接以美元显示；如果站点关闭了货币显示，则会显示原始额度数字。价格页里的单价也支持在「$ / 1K tokens」与「$ / 1M tokens」之间切换。

## 在哪里看价格

打开「可用模型」页面，可以看到全部模型的输入价格与输出价格：

- **分组**：右上角切换分组，价格随分组倍率变化，倍率会以 `x1`、`x0.5` 这样的徽标标出，倍率为 0 的模型显示「免费」。
- **只显示可用**：默认开启，只列出你当前分组能调用的模型。
- **类型**：区分「按量付费」和「按次付费」两种计价方式。
- **单位**：在「显示」菜单里切换 K / M 单位。
- **查看详情**：点击行尾的眼睛图标，可以看到该模型在各分组下的价格，以及缓存、音频、推理等扩展倍率。

如果某个模型显示「价格未配置」，说明站点尚未为它设置价格，调用时可能被直接拒绝。

## 按量付费（tokens）

绝大多数对话与文本模型按 token 计费，输入和输出各自独立计价：

> 本次花费 = 输入 token 数 × 输入单价 + 输出 token 数 × 输出单价

其中的单价就是价格页上显示的价格，也就是**模型单价 × 分组倍率**。输入和输出各用各的价格，不会再乘任何额外系数。

## 按次付费（times）

绘图、音乐等模型按次计价：只要一次调用成功返回，就收取固定的单次价格，与消耗了多少 token 无关。这类模型在价格页的「类型」列显示为「按次付费」。

## 扩展倍率

有些用量属于特殊类型的 token，例如命中缓存的输入、音频、推理过程。它们会按各自的倍率折算后计入输入侧或输出侧：

| 名称 | 计入侧 | 含义 |
| --- | --- | --- |
| `cached_tokens` | 输入 | 命中提示词缓存的输入 token |
| `cached_write_tokens` | 输入 | 写入缓存（5 分钟有效期） |
| `cached_write_1h_tokens` | 输入 | 写入缓存（1 小时有效期） |
| `cached_read_tokens` | 输入 | 从缓存读取 |
| `openai_cache_write_tokens` | 输入 | OpenAI 缓存写入 |
| `input_audio_tokens` | 输入 | 音频输入 |
| `input_text_tokens` | 输入 | 文本输入 |
| `input_image_tokens` | 输入 | 图像输入 |
| `output_audio_tokens` | 输出 | 音频输出 |
| `output_image_tokens` | 输出 | 图像输出 |
| `output_text_tokens` | 输出 | 文本输出 |
| `reasoning_tokens` | 输出 | 推理过程消耗的 token |

倍率的含义很直接：**倍率为 1 表示与普通 token 同价，大于 1 表示更贵，小于 1 表示更便宜**。例如缓存读取的默认倍率是 0.1，命中缓存的那部分输入只按十分之一计价；1 小时有效期的缓存写入默认倍率是 2。

每个模型的实际倍率以「查看详情」里显示的为准，未单独配置的类型按普通 token 计价。

## 长上下文分档

少数模型配置了长上下文分档：当本次请求的输入 token 超过设定阈值时，整次请求的输入价与输出价会各自乘上对应的分档倍率。未超过阈值时价格不变。

## 预扣与结算

发起请求时，系统会按输入 token 先预扣一部分额度；请求结束后按实际用量结算，多退少补。因此：

- 余额或 API Key 额度不足时，请求会在发出前就被拒绝；
- 流式请求过程中如果额度耗尽，连接会被中断；
- 日志里看到的花费是结算后的最终金额。

## 查看账单明细

- 「用量」页面：按时间、模型、API Key、应用维度看消费金额、Token 量和请求数。
- 「日志」页面：逐条请求的花费；展开某条记录的详情，可以看到本次的实际输入价格、输出价格、分组倍率、原始计费与最终花费，以及缓存、推理等各类 token 的拆分。
- 「账单」页面的「账户流水」标签（从侧边栏底部的用户菜单进入「账单」）：充值、兑换、系统调整等账务记录，这些不在请求日志里。

兑换码可能被限定用途：「仅个人」的码只能兑入个人账户，「仅组织」的码只能在组织上下文兑入组织额度池，用错上下文会被拒绝且兑换码保持可用，详见 [组织](/zh/guide/organization)。
