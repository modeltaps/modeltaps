# Quickstart

This page walks you through your first call in a few minutes: sign in → create an API key → run the ready-made test command → plug the address and key into your own application.

## 1. Sign in and open the dashboard

After signing in with your account you land on the **Dashboard**, which shows:

- available quota, today's request count, today's spend and today's token volume;
- usage trends and model usage over the last seven days;
- **Available models**, the list of models you can call under your current group;
- the **Quickstart** card — clicking one of the chat client buttons automatically creates a chat-only API key for you and opens that client with the key already filled in, which is a good way to try things out first.

The balance row at the bottom of the sidebar shows your available quota; clicking it opens **Top up**. The group you belong to determines which channels you can be routed to and your requests-per-minute limit.

## 2. Create an API key

For real integration, create your own API key on the **API Keys** page:

1. Click **New API key**;
2. Fill in the **Name** (required) — it is used later to tell applications apart in logs and usage;
3. **Expiry** defaults to **Never expires**; turn the switch off to pick a specific time;
4. Leave **Quota** empty for no limit, or enter a number to cap how much quota this API key may consume;
5. **Group** lets you pin this API key to a specific channel group; leave it empty to use your account's default group;
6. Submit.

For finer control over quota, periodic resets, model restrictions and IP allowlists, see [API keys and quota](/guide/tokens).

::: tip API key quota and account quota are two different things
An API key quota only caps how much that single key may use. Actual charges are still drawn from your account quota. If either one is insufficient, the request is rejected.
:::

## 3. Verify with the test command

Find the API key you just created in the **API Keys** list and open its **Test command**. In the dialog you can switch between the OpenAI / Claude / Gemini tabs and pick a model; Modeltaps assembles your real key, site address and model name into a `curl` command you can run as-is. Click **Copy command** and paste it into a terminal.

If a protocol tab reports that no models are available, there is no channel of that type in your current group — switch back to the **OpenAI** tab to test.

## 4. Connect your own application

Once you have an API key, do two things in your application:

- point the API address (base URL) at your Modeltaps site address;
- replace the API key with the one generated by Modeltaps (a string starting with `sk-`).

Addresses and request examples for all three protocols are in [API access](/guide/api).

## 5. Top up and redeem

When you need more quota, click the balance row at the bottom of the sidebar to open the **Top up** page:

- **Online payment**: enter an amount and choose a payment method; the page shows the discounted price, the processing fee and the amount actually charged;
- **Redemption code**: paste the code you received into the input box and click **Redeem** to credit your account.

Top-ups, referral rewards and other accounting records do not appear in the request logs — open **Billing** from the user menu at the bottom of the sidebar and switch to the **Transactions** tab instead.

If you share one quota pool with colleagues, top-ups and quota can be managed together in an organization — see [Organizations](/guide/organization).
