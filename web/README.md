# Modeltaps Web

The Modeltaps web frontend — a React + Vite single-page application built with Material UI (MUI).

## Development

```bash
pnpm install  # install dependencies (pnpm workspace; lockfile at the repository root)
pnpm dev      # start the dev server
pnpm build    # produce a production build in build/
```
