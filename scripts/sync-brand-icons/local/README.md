# Local brand marks

Official marks of brands that `@lobehub/icons-static-svg` does not ship. `sync.mjs` copies them
into `common/brandicon/assets/` next to the package's icons. Each brand needs `<key>.svg` (one
color, `fill="currentColor"`) and may have `<key>-color.svg`. Check a newer package version first
and drop the local file once the package has the brand.

| Key | Brand | Source |
| --- | --- | --- |
| `requesty` | Requesty | Traced from the official logo on requesty.ai (`/logo_requesty_dark.png`, `/apple-icon.png`); no SVG is published. Blue `#1877FF`. |
| `parallel` | Parallel Web Systems | Official site icon, parallel.ai `/icon.svg`; the one-color version drops the white disc. |
| `openbmb` | OpenBMB | Official site icon, openbmb.cn `/favicon.svg`. |
| `byteplus` | BytePlus | Official footer mark on byteplus.com (`byteplus_logo_footer.svg`, white); colored with the favicon's blue `#0061FF`. |
| `nace` | Nace AI | Official site icon, nace.ai `/icon.svg`; the one-color version keeps the letters as cut-outs. |
